# Roboto

Source: Google Fonts, Roboto v51.
The unchanged variable Latin WOFF2 file supports the 300, 400, 500, and 700 weights used by this site.

- CSS source: https://fonts.googleapis.com/css2?family=Roboto:wght@300;400;500;700&display=swap
- Font source: https://fonts.gstatic.com/s/roboto/v51/KFO7CnqEu92Fr1ME7kSn66aGLdTylUAMa3yUBA.woff2
- License source: https://raw.githubusercontent.com/google/fonts/main/ofl/roboto/OFL.txt

Distributed under the SIL Open Font License 1.1; see OFL-Roboto.txt.
The website loads this local font file, with Arial and Helvetica Neue as fallbacks. No runtime Google Fonts request is made.
